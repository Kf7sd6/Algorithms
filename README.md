# Алгоритмы: индивидуальная программа с нуля

Программа учитывает слабое знакомство даже с базовыми структурами данных, материалы преподавателя и зелёные стрелки на оглавлении Кормена. Никакие темы ещё не считаются освоенными.

## Открыть сначала

1. [Первые две недели](roadmap/02-first-two-weeks.md) — ближайшие небольшие занятия.
2. [Актуальный прогресс](CURRENT_PROGRESS.md) — где остановились и что делать дальше.
3. [Весь маршрут](roadmap/00-learning-plan.md) — общая последовательность и нагрузка.

## Где что лежит

| Путь | Для чего |
| --- | --- |
| `topics/` | Объяснения, чтение и упражнения по 22 модулям |
| `roadmap/` | Порядок, зависимости, приоритеты, первые занятия и связь с курсом преподавателя |
| `practice/` | Входная проверка, внешние задачи и памятка решения |
| `solutions/` | Будущие собственные решения и измерения; сейчас только правила именования |
| `ai/` | Контекст и журнал сессий для следующих ассистентов |
| `sources/` | Проверенные источники и объяснение выбора материалов |
| `AGENTS.md` | Как продолжать обучение и обновлять документы |

Статусы не дублируются в папках: единственный актуальный учёт — `CURRENT_PROGRESS.md`. История разбора хранится отдельными записями сессий.
