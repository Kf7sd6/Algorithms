# Алгоритмы: индивидуальная программа с нуля

Программа учитывает слабое знакомство даже с базовыми структурами данных, материалы преподавателя и зелёные стрелки на оглавлении Кормена. Никакие темы ещё не считаются освоенными.

## Открыть сначала

1. [Первые две недели](roadmap/02-first-two-weeks.md) — ближайшие небольшие занятия.
2. [Актуальный прогресс](CURRENT_PROGRESS.md) — где остановились и что делать дальше.
3. [Весь маршрут](roadmap/00-learning-plan.md) — общая последовательность и нагрузка.

## Где что лежит

| Путь | Для чего |
| --- | --- |
| `topics/` | Краткие паспорта, чтение и исходные упражнения по 22 модулям |
| `materials/` | Развёрнутые учебные пакеты: конспект, практика и отдельные разборы; сейчас готовы M00 и M01 |
| `roadmap/` | Порядок, зависимости, приоритеты, первые занятия и связь с курсом преподавателя |
| `practice/` | Входная проверка, внешние задачи и памятка решения |
| `solutions/` | Будущие собственные решения и измерения; сейчас только правила именования |
| `ai/` | Контекст, журнал сессий и план подготовки полных учебных материалов |
| `sources/` | Проверенные источники и объяснение выбора материалов |
| `AGENTS.md` | Как продолжать обучение и обновлять документы |

Факты об освоении тем не дублируются в папках: единственный актуальный учебный учёт — `CURRENT_PROGRESS.md`. История разбора хранится отдельными записями сессий.

## Полные конспекты

Доступен [полный M00 «Как читать и выполнять программу»](materials/M00/README.md): небольшие части от присваиваний до функции, [три исходных упражнения](materials/M00/practice.md) и отдельные [подсказки и разборы](materials/M00/help.md).

Также готов [полный M01 о массивах](materials/M01/README.md): пошаговые примеры, обоснования, [практика](materials/M01/practice.md), отдельные [подсказки и решения](materials/M01/help.md). Другие пакеты готовятся по очереди; все готовые тексты находятся в [каталоге материалов](materials/README.md).

Для авторов курса: [порядок работы](ai/materials/README.md), [состав всех 22 тем](ai/materials/module-map.md), [состояние подготовки и ближайшая задача](ai/materials/status.md). Исходные паспорта и упражнения сохранены; готовность конспекта не меняет учебный статус темы.

Дата подготовки: 21 октября 2026 года, часовой пояс пользователя Asia/Yekaterinburg. Текущий репозиторий: [Kf7sd6/Algorithms](https://github.com/Kf7sd6/Algorithms), закрытый, основная ветка `main`.
