## Текущая точка

Подготовлены [порядок работы](README.md), [карта всех модулей](module-map.md) и [шаблон](../templates/material.md). Полные пакеты `materials/Mxx/` ещё не создавались. Существующие паспорта и упражнения сохранены; в 22 паспортах найдено 87 исходных ID задач. Некоторые ID включают несколько больших действий, поэтому это не оценка трудоёмкости.

**Следующая авторская задача:** подготовить пилотный M01 по шаблону: самостоятельный конспект, 4–5 небольших обязательных заданий из имеющихся P1–P4 с нужным дроблением, отдельные подсказки и разборы. Сначала прочитать фактические фрагменты S08 ArrayStack и актуальной лекции 3 S01; если S01 недоступен, честно отметить замену доступным первичным текстом. Для вставки явно задать вместимость и допустимые позиции, для поиска — поведение на пустом входе. Затем проверить формат перед расширением остальных тем.

**После пилота:** M00 в минимальном объёме, M02, M03/M04. Это порядок авторской работы; учебный вход по-прежнему выбирается диагностикой M00/M01.

## Значения статусов

| Статус | Что подтверждено |
| --- | --- |
| Запланировано | Есть паспорт и задание в карте; полного пакета нет |
| Источники прочитаны | Проверены точные фрагменты для объявленного охвата, зафиксированы ограничения |

| Готово к первому проходу | Проверены конспект, практика и разборы первого слоя, продолжение перечислено |
| Готов весь согласованный объём | Проверены основной проход и продолжение из карты |
| Требует исправления | Указана конкретная содержательная ошибка/недоступность/неполнота |
