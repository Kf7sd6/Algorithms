# Память учебного процесса для ассистентов

Сначала читать [актуальный прогресс](../CURRENT_PROGRESS.md), затем [контекст](context.md) и указанную там последнюю запись сессии. Полные правила — [AGENTS.md](../AGENTS.md).

| Путь | Назначение |
| --- | --- |
| `context.md` | Цели, исходный уровень и границы программы |
| `decisions.md` | Почему был выбран или изменён маршрут |
| `sessions/` | Факты каждого завершённого занятия/этапа подготовки |
| `templates/session.md` | Шаблон новой записи |
| `materials/README.md` | Как писать полные конспекты по источникам и практику без перегрузки |
| `materials/module-map.md` | Состав, доказательства и источники всех 22 будущих пакетов |
| `materials/status.md` | Редакционное состояние подготовки и следующий авторский шаг |
| `templates/material.md` | Шаблон конспекта, практики, подсказок и разборов |

Фактический учебный статус тем здесь повторно не ведётся. Редакционный учёт отвечает только на вопрос, какие материалы написаны и проверены. Если заметка сессии и актуальный прогресс расходятся, выяснить причину и исправить актуальный учёт по подтверждённым фактам; не угадывать достижения.
