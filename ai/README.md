# Память учебного процесса для ассистентов

Сначала читать [актуальный прогресс](../CURRENT_PROGRESS.md), затем [контекст](context.md) и указанную там последнюю запись сессии. Полные правила — [AGENTS.md](../AGENTS.md).

| Путь | Назначение |
| --- | --- |
| `context.md` | Цели, исходный уровень и границы программы |
| `decisions.md` | Почему был выбран или изменён маршрут |
| `sessions/` | Факты каждого завершённого занятия/этапа подготовки |
| `templates/session.md` | Шаблон новой записи |

Фактический статус тем здесь повторно не ведётся. Если заметка сессии и актуальный прогресс расходятся, выяснить причину и исправить актуальный учёт по подтверждённым фактам; не угадывать достижения.
