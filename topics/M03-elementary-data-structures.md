## Объяснение и порядок разбора

Сначала отделим правило использования от способа хранения. **Стек** выдаёт последним добавленный элемент: положили A, затем B; первым снимем B. **Очередь** выдаёт первым добавленный: A, затем B; первым выйдет A. Это правила операций. Реализовать их можно несколькими способами.

Для стека на динамическом массиве нужны добавление в конец, чтение последнего и удаление последнего. С пустым стеком заранее определяем поведение: сообщить об ошибке или не разрешать такую команду по условию. Добавление в конец массива — амортизированно O(1) при геометрическом увеличении вместимости; удаление последнего без сжатия — O(1).

Простейшая очередь на массиве с удалением первого через сдвиг тратит O(n) на такое удаление. Вместо этого храним индексы головы и следующей свободной позиции. В **кольцевой очереди** после конца массива переходим к началу. Чтобы не спутать пустое состояние с полным, можно хранить размер. При фиксированной вместимости вставка и удаление занимают O(1), переполнение обрабатываем явно.

У **связного списка** узлы не обязаны лежать рядом. Каждый хранит значение и ссылку на следующий узел; у двусвязного есть и ссылка на предыдущий. Чтобы добраться до i-го узла, обычно нужно пройти цепочку. Удалить узел после уже известного узла можно за O(1); сначала найти нужное место может стоить O(n). Это разные части операции.

Порядок занятий: стек на массиве → очередь → рисунок узла и ссылки → односвязный список → двусвязный и кольцевой список. До кода списка отдельно разбираем `nullptr`, адрес, ссылку на узел и изменение связи. Ручное управление памятью изучаем на маленьких примерах с понятным владельцем узлов; оно не должно заслонять смысл структуры.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M03-P1.** Выполнить push(4), push(7), pop(), push(2), pop(), pop(). Записать возвращаемые значения и состояние стека после каждого шага. Повторить с правилом очереди.

**M03-P2.** Реализовать стек и кольцевую очередь вместимости 3. Проверить пустоту, заполнение и переход индекса через конец массива.

**M03-P3.** Нарисовать список 4 → 7 → 2. Удалить средний узел, затем первый и последний; выписать, какие ссылки меняются. После рисунка реализовать маленький односвязный список.

**M03-P4.** Проверить скобочную последовательность из круглых и квадратных скобок стеком. Придумать корректную строку и три разных причины некорректности.

## Частые ошибки

- Объявлять вставку в список O(1), забыв поиск позиции.
- Терять оставшуюся цепочку при изменении next.
- Использовать одну и ту же позицию головы и хвоста без способа различать полную и пустую очередь.
