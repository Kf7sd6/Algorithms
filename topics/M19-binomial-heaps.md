# M19. Биномиальные кучи

**Место в программе:** Приоритет по зелёной стрелке.  
**Главы по изображению:** 19.  
**Вход:** [M11](M11-binary-heaps.md), [M05](M05-recursion-and-recurrences.md), [M03](M03-elementary-data-structures.md).  
**Ориентир:** 6–10 часов первичного разбора и практики; темп уточняется по работе.

## Объяснение и порядок разбора

У обычной двоичной кучи быстро получить минимум, но слияние двух произвольных куч не становится автоматически логарифмическим. Биномиальная куча строит сливаемую очередь с приоритетом из набора специальных деревьев.

Дерево B₀ — один узел. B_k получается объединением двух B_(k−1): один корень становится ребёнком другого. У него 2^k узлов, степень корня k и высота k. При связывании выбираем меньший корень родителем, сохраняя свойство минимальной кучи.

В классической нормализованной биномиальной куче не более одного дерева каждой степени. Степени корней соответствуют единичным разрядам числа элементов. Поэтому корней O(log n), а объединение напоминает сложение двоичных чисел с переносом. Это сходство надо проследить на рисунке, а не только запомнить.

Изучаем merge корневых списков по степеням и link деревьев одинаковой степени. Различаем эти две операции и весь meld/union. Для вставки можно объединить с кучей из одного узла. Для извлечения минимума находим минимальный корень, удаляем его и объединяем оставшуюся кучу с его детьми в требуемом порядке степеней.

В классической версии из Кормена с поиском минимума по корням: minimum O(log n), insert/union/extract_min/decrease_key/delete имеют O(log n) верхние оценки. Вариант с отдельным указателем на минимум улучшает чтение минимума; ленивые варианты меняют и другие оценки. Таблицу всегда подписываем конкретной реализацией. При decrease_key через обмен содержимым узлов важно понять, как сохраняется связь внешнего идентификатора с записью.

Биномиальная куча — структурная подготовка к фибоначчиевой. Её можно проходить после двоичной кучи независимо от B-деревьев и строковых алгоритмов. Перед началом обязательно повторить дерево, ссылки, индукцию и двоичную запись числа.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M19-P1.** Построить B₀, B₁, B₂, B₃ и доказать индукцией число узлов. Указать набор степеней для кучи из 13 элементов.

**M19-P2.** Вручную слить кучи размеров 5 и 7, показывая переносы по степеням и выбор родителя по ключу.

**M19-P3.** Реализовать link, union, insert и extract_min; проверить порядок степеней и свойство кучи после каждой операции.

**M19-P4.** Разобрать decrease_key и delete по известной записи. Сравнить оценки с двоичной кучей, явно назвав реализацию поиска минимума.

- [ ] Сам прослеживаю extract_min и восстановление инвариантов.
- [ ] Привожу таблицу оценок именно изученной версии.

## Частые ошибки

- Путать биномиальную и двоичную кучи.
- Допускать две одинаковые степени в нормализованном корневом списке.
- Терять идентичность записи при обмене ключами.
