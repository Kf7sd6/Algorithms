# M14. Минимальный остов и нужный минимум DSU

**Место в программе:** Приоритет; DSU — связка из главы 21.  
**Главы по изображению:** 23.  
**Вход:** [M13](M13-graph-traversals.md), [M12](M12-greedy-algorithms.md), [M11](M11-binary-heaps.md).  
**Ориентир:** 6–10 часов первичного разбора и практики; темп уточняется по работе.

## Объяснение и порядок разбора

Для взвешенного неориентированного связного графа минимальный остов соединяет все вершины, содержит V−1 рёбер, не содержит циклов и имеет минимальный суммарный вес. Его задача — удешевить всю сеть связей; кратчайшие маршруты от одной точки он не обязан сохранять.

**Краскал** просматривает рёбра по неубыванию веса и добавляет ребро, если его концы пока принадлежат разным компонентам. Для этого нужны операции создать множество, найти представителя и объединить два множества. Такая структура называется системой непересекающихся множеств, или DSU.

DSU впервые разбираем прямо здесь: лес родительских ссылок; корень — представитель; объединение по рангу/размеру. Уже объединение по размеру без сжатия путей ограничивает высоту O(log V). Затем добавляем сжатие путей. Для рангов и сжатия известна амортизированная оценка O(α(V)) на операцию в стандартной серии, где α растёт крайне медленно. Полное доказательство этой оценки из неотмеченной главы 21 сейчас не требуется; понимание связи компонентов и корректности проверяем обязательно.

**Прим** растит одно дерево, каждый раз присоединяя самый дешёвый переход из выбранной части во внешнюю. Изучаем простой вариант O(V²), затем вариант со списками и очередью с приоритетом. Гарантии зависят от реализации очереди и обработки устаревших записей.

Оба алгоритма обосновывает безопасное ребро, пересекающее подходящий разрез. Разбираем обмен с оптимальным остовом и случай одинаковых весов: оптимальный остов не всегда единственен. Отрицательные веса допустимы. Если граф несвязен, единого остова нет; можно явно решать задачу минимального остовного леса.

Для Краскала основной вклад — сортировка рёбер O(E log E); работу DSU называем отдельно. Нельзя выучить только картинку жадного выбора и пропустить проверку циклов.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M14-P1.** На треугольнике с весами 1,2,10 найти остов и сравнить с кратчайшими путями от конца ребра веса 10. Затем подобрать свой пример, где дерево кратчайших путей и минимальный остов различаются.

**M14-P2.** Реализовать DSU и Краскала. Проверить повторы весов, несвязный граф и ребро внутри уже объединённой компоненты.

**M14-P3.** Вручную выполнить Прима и Краскала на одном графе из 6 вершин. Совпадение суммарной стоимости объяснить через оптимальность, а не одинаковый порядок рёбер.

**M14-P4.** Записать доказательство безопасного ребра через разрез. После этого вернуться к графическому примеру матроида из M12.

## Когда можно двигаться дальше

- [ ] Отличаю остов от маршрута и кратчайших путей.
- [ ] Объясняю инвариант компонент Краскала и безопасного разреза.
- [ ] Знаю, какие предпосылки даёт граф и какой результат возвращать при несвязности.

## Частые ошибки

- Строить минимальный остов ориентированного графа тем же правилом без новой постановки.
- Считать DSU механизмом нахождения кратчайших путей.
- Ожидать единственность при равных весах.
