# M12. Жадный выбор и его доказательство

**Место в программе:** Приоритет по зелёной стрелке.  
**Главы по изображению:** 16.  
**Вход:** [M06](M06-comparison-sorting.md), [M11](M11-binary-heaps.md).  
**Ориентир:** 5–8 часов первичного разбора и практики; темп уточняется по работе.

## Объяснение и порядок разбора

Жадный алгоритм делает локальный выбор и продолжает решение без пересмотра этого выбора. Само описание «берём лучшее сейчас» ещё не доказывает оптимальность. Нужно связать локальное действие с существованием оптимального полного ответа.

Для непересекающихся мероприятий выбираем совместимое мероприятие с самым ранним окончанием. Пусть в некотором оптимальном расписании первое мероприятие заканчивается позже выбранного нами. Заменяем первое выбранным: число мероприятий не уменьшается, место для остальных сохраняется. Затем применяем такое же рассуждение к остатку. Это **обменное доказательство**.

Полезно проверить похожие правила: самое раннее начало и самая короткая длительность могут дать плохой результат. Если у мероприятий появились разные ценности, прежнее правило уже не гарантирует максимум суммарной ценности. Контрпример — часть изучения метода.

Следующий пример — код Хаффмана. Из двух наименьших частот собираем общий узел, возвращаем его в очередь с приоритетом и повторяем. Изучаем префиксный код, стоимость как взвешенную длину, безопасное объединение двух малых частот. Здесь пригодятся дерево и куча, но не полный курс графов.

Из главы также берём **матроид** как точное описание некоторых систем, где жадный выбор работает. Семейство допустимых подмножеств должно быть непустым, наследственным и удовлетворять свойству обмена: из большего независимого множества можно добавить подходящий элемент к меньшему. Сначала разбираем простой пример «любые подмножества размера не более k». Затем читаем формулировку и идею доказательства жадного выбора по весам. Графический пример получит смысл в M14; возвращение к нему — закрепление, а не условие входа.

Полный модуль динамического программирования из главы 15 пока отложен по приоритетам пользователя. Для понимания границ жадности достаточно одного контрпримера и объяснения, что иной способ может учитывать больше вариантов. Беллман — Форд позднее будет разобран без требования пройти всю главу 15.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M12-P1.** Для мероприятий [0,4), [1,2), [2,3), [3,5) найти максимальное число совместимых. Явно принять совместимость при равенстве конца и начала.

**M12-P2.** Реализовать выбор по раннему окончанию и записать обменное доказательство. Придумать контрпример к выбору по раннему началу.

**M12-P3.** Построить дерево Хаффмана для частот 2,3,7,9. Вычислить стоимость и проверить префиксность.

**M12-P4.** Проверить аксиомы матроида для всех подмножеств размера не более 2. На маленьком примере разобрать обмен и выбор по убыванию неотрицательных весов.

## Частые ошибки

- Доказывать оптимальность несколькими удачными примерами.
- Переносить правило на взвешенную задачу без нового доказательства.
- Подменять доказательство словами «очевидно, так выгоднее».
