## Объяснение и порядок разбора

Алгоритм — точное описание действий, которое для допустимых входных данных заканчивается и выдаёт требуемый результат. Программа записывает эти действия на языке, который исполняет компьютер. На старте достаточно уметь проследить, как меняются несколько переменных.

Начнём с последовательности `7, 2, 9`. Хотим получить сумму. Переменная `sum` сначала равна нулю; после первого числа — 7, после второго — 9, после третьего — 18. Запись «после второго» относится к числу обработанных элементов. Индексы массива обсудим в M01.

Нужные элементы языка: целое число, присваивание, сравнение, условие, цикл, функция, последовательность значений. Присваивание `x = x + 1` сначала вычисляет правую часть по старому значению `x`, затем сохраняет новое. Равенство при проверке условия в C++ пишется `==`.

Рабочий язык по умолчанию — C++ из курса преподавателя. Это настройка программы обучения; реальное владение C++ пока неизвестно. Первое объяснение допускает обычные слова и псевдокод, затем переносим тот же алгоритм в C++. Изучать одновременно второй язык не требуется. Если даже циклы пока мешают, этот модуль растягиваем; новые алгоритмы не добавляем до понимания выполнения программы.

Установка среды нужна только при отсутствии рабочего компилятора. Если программа уже запускается, переустановка не является учебной задачей. Стандарт языка сверяем с требованиями преподавателя; приведённый в его лекциях сокращённый синтаксис параметров `auto` может требовать C++20.

**Порядок работы:** сначала входная проверка из `practice/00-diagnostic.md`; затем ручная таблица значений; потом самостоятельная программа. Для чтения данных: число `n`, после него `n` чисел. На этом шаге ввод корректный; обработку произвольного пользовательского интерфейса не разрабатываем.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M00-P1.** По шагам вычислить `x=4; x=x+3; if (x>5) x=x-2`. Выписать значения после каждой строки и объяснить условие.

**M00-P2.** Без копирования готовой программы прочитать n целых чисел и вывести их сумму. Для n=0 договориться, что сумма равна 0. Проверить нули и отрицательные числа; подобрать тип, вмещающий сумму.

**M00-P3.** Написать функцию, которая считает число положительных элементов последовательности. На примере [-2, 0, 5, 5] показать каждое изменение счётчика.

## Когда можно двигаться дальше

- [ ] Объясняю разницу между присваиванием и проверкой равенства.
- [ ] Прослеживаю короткий цикл вручную и нахожу ошибку в его границах.
- [ ] Сам запускаю небольшую программу и объясняю её строки. Если это уже умею, прохожу модуль по проверке без лишнего чтения.

## Частые ошибки

- Считать незнакомый синтаксис доказательством неспособности придумать алгоритм.
- Принимать запуск чужого кода за самостоятельное владение циклом.
