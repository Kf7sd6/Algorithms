## Объяснение и порядок разбора

Линейный поиск проверяет элементы по одному и работает с произвольным порядком. Двоичный поиск использует известный порядок, чтобы отбрасывать сразу часть позиций. Для обычного поиска числа это отсортированный массив.

Начнём с одной задачи: найти первую позицию, где элемент не меньше x. Пусть `[l,r)` — ещё рассматриваемый участок. Слева от l все элементы меньше x; начиная с r все элементы не меньше x. В начале l=0, r=n, обе внешние части пусты. Если `a[mid]<x`, границу l переносим на `mid+1`; иначе r переносим на mid. При l=r искомая граница найдена, в том числе когда ответ равен n.

Для массива `[1,3,3,8]` и x=3 граница равна 1. Для проверки наличия x после этого нужно убедиться, что индекс меньше n и значение действительно равно x. Для первой позиции строго больше x меняется условие; так появляются `lower_bound` и `upper_bound`.

На каждом шаге размер участка уменьшается примерно вдвое: O(log n) сравнений; память итеративной версии O(1). Середину удобно считать как `l+(r-l)/2`. Пустой вход и повторяющиеся значения — обычные случаи задачи, а не исключения.

Общий принцип — поиск границы у условия, которое вдоль рассматриваемых позиций меняется только один раз. Двоичный поиск по ответу оставим на закрепление после освоения поиска в массиве. Для связного списка малое число сравнений ещё не гарантирует такое же время: переход к середине сам может потребовать прохода.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M04-P1.** На [1,3,3,8] вручную найти нижние границы для 0, 3, 4, 9, записывая l, r и mid.

**M04-P2.** Реализовать одну версию lower_bound на [l,r). По ней написать contains. Проверить пустой массив, один элемент, повторы и ответы на обеих границах.

**M04-P3.** Найти число вхождений x двумя поисками границ и объяснить сложность.

**M04-P4.** Разобрать ошибочную версию, где при a[mid]<x делается l=mid. Найти вход с зацикливанием и объяснить меру уменьшения интервала.

## Когда можно двигаться дальше

- [ ] Записываю смысл обеих границ до написания цикла.
- [ ] Доказательно объясняю сохранение ответа и завершение.
- [ ] Не читаю a[n] при ответе n.

## Частые ошибки

- Смешивать закрытый и полуоткрытый интервалы.
- Применять поиск к неупорядоченному условию.
- Выучить формулы границ без их смысла.
