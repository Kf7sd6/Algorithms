# Практика

Основные задачи находятся рядом с объяснением в файлах `topics/`. Их идентификатор имеет вид `M01-P2`. Начинать с маленького ручного примера и только потом писать код.

| Файл | Когда открывать |
| --- | --- |
| [Входная проверка](00-diagnostic.md) | На первом учебном занятии, только стартовая часть |
| [Выбранные внешние задачи](01-external-tasks.md) | После соответствующей темы и своей маленькой реализации |
| [Карточка решения](02-solution-checklist.md) | При оформлении новой самостоятельной задачи |

Решения складываются в `solutions/`. Учёт выполненного — в `CURRENT_PROGRESS.md`; отдельный второй журнал статусов не нужен.

Собственные упражнения созданы для постепенного входа. Они не имеют фиктивных ссылок на контест и не выдаются за задания преподавателя. Для некоторых глубоких доказательств нужно обратиться к указанной главе источника; короткий конспект не заменяет её целиком.
