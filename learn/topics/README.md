# Темы для самостоятельного изучения

Начинать с M00, M01, M02 и базовой части M03. Номера модулей задают удобный маршрут; обязательные зависимости указаны отдельно. Оценки времени — предварительные, их можно пересматривать.

В каждом файле есть краткий конспект, порядок чтения, собственные упражнения и проверка понимания. Это стартовые учебные материалы и задания к источникам, а не замена всем доказательствам Кормена. В сложных главах отдельно отмечена глубина первого и повторного проходов.

Развёрнутые пакеты перечислены в [каталоге материалов](../README.md). Сейчас готовы [M00: выполнение программы](M00/README.md), [M01: массивы](M01/README.md), [M02: стоимость и доказательства](M02/README.md), [M03: стек, очередь и списки](M03/README.md) и [M04: линейный и двоичный поиск](M04/README.md) с отдельной практикой и разборами; в таблице готовые темы ведут к полным конспектам, остальные — к кратким планам.
