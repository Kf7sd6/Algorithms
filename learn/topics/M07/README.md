## Объяснение и порядок разбора

Линейные сортировки используют свойства ключей, выходящие за модель сравнений. Поэтому они могут обходить нижнюю границу для сравнительных алгоритмов; противоречия нет.

**Подсчёт** для целых ключей 0…k−1 сначала получает частоты. Восстановить отсортированные числа можно по частотам. Чтобы устойчиво переставить целые записи, нужны накопленные количества, выходной массив и согласованный порядок его заполнения. Например, записи `(2,A),(1,B),(2,C)` после устойчивой сортировки сохраняют A перед C.

Стоимость обычной сортировки подсчётом — Θ(n+k) времени и O(n+k) дополнительной памяти для устойчивого варианта с выходным массивом. Если диапазон ключей огромен относительно n, эта структура может оказаться невыгодной. Для отрицательных значений можно сдвинуть ограниченный известный диапазон; большой диапазон от этого не станет маленьким.

**Поразрядная сортировка** последовательно обрабатывает разряды. В варианте LSD начинаем с младшего разряда и каждый проход делаем устойчивым. Тогда порядок уже рассмотренных младших разрядов сохраняется внутри одинакового текущего разряда. Для d разрядов основания b получаем Θ(d(n+b)) при обычном подсчёте на каждом проходе. Слово «линейная» зависит от d и b.

**Карманная сортировка** распределяет ключи по диапазонам, сортирует внутри и объединяет карманы. Ожидаемая линейная работа требует предположений о распределении и подходящих параметров; если все элементы попали в один карман, быстроты может не быть.

Заканчиваем практической лабораторной преподавателя: сравниваем шесть сортировок на одинаковых исходных данных. Метод измерения важен, но он не заменяет теоретического подсчёта операций. Требования и оговорки к большим размерам вынесены в `learn/plan/03-teacher-alignment.md`.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M07-P1.** Устойчиво отсортировать записи (2,A),(1,B),(2,C),(0,D) подсчётом. Показать частоты, накопленные количества и места записи.

**M07-P2.** Реализовать подсчёт для ограниченного диапазона целых чисел и LSD для неотрицательных чисел. Проверить повторы, нули и разное число разрядов.

**M07-P3.** Найти пример, где неустойчивый разрядный проход разрушает результат LSD. Затем сравнить n=100 и диапазоны k=10, 1000, 10⁹ по памяти.

**M07-P4.** Подготовить протокол лабораторной: типы входов, размеры, повторы, проверка ответа, что включается во время. Реальные данные измерений пока не выдумывать.

## Когда можно двигаться дальше

- [ ] Объясняю параметры k, d и b в оценках.

- [ ] Не обещаю карманной сортировке линейный худший случай.

## Частые ошибки

- Забывать длину диапазона ключей.
- Смешивать сортировку самих чисел и устойчивую перестановку записей.
- Объявлять ускорение доказанным только по линии тренда.
