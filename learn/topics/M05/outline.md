## Объяснение и порядок разбора

Рекурсивная функция обращается к той же функции на меньшем входе. Нужны базовый случай и объяснение, почему каждый следующий вызов приближает к нему. Каждый незавершённый вызов сохраняет своё состояние в стеке; поэтому глубина рекурсии влияет на память.

Сначала проследим сумму элементов: сумма пустого участка равна 0; сумма участка длины n получается из первого элемента и суммы оставшихся n−1 элементов. Это описание правильного результата. Стоимость вызовов — другое соотношение: `T(n)=T(n−1)+Θ(1)`, откуда Θ(n) времени и Θ(n) глубины обычной рекурсивной реализации.

**Рекуррентное соотношение для времени** выражает работу большого входа через работу меньших входов и дополнительные действия. Для деления массива пополам с двумя вызовами и линейным объединением: `T(n)=2T(n/2)+Θ(n)`. На каждом уровне суммарно Θ(n) работы; уровней Θ(log n); итог Θ(n log n). Позже это будет анализом сортировки слиянием.

Разбираем три инструмента: раскрытие/дерево рекурсии; подстановка с доказательством индукцией; основная теорема о рекуррентных соотношениях. Её базовую форму применяем к `aT(n/b)+f(n)`, где a≥1, b>1 — постоянные. Сравниваем f(n) с `n^(log_b a)`; в третьем случае нужна и регулярность, а не только «f больше». Точные условия читаем у Кормена на конкретном примере. К `T(n)=T(n−1)+n` эта форма не применяется.

Математический мост здесь небольшой: база и шаг индукции, геометрическая сумма, логарифм. Полный отдельный курс дискретной математики до первой рекурсии не нужен. Уравнение для значений Фибоначчи и уравнение для времени наивного вычисления Фибоначчи разбираем раздельно.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M05-P1.** Нарисовать последовательность вызовов суммы для [4,1,3]. Указать состояния в момент самого глубокого вызова и при возврате.

**M05-P2.** Решить T(n)=T(n−1)+1, T(n)=T(n/2)+1, T(n)=2T(n/2)+n при постоянной базе. Для удобства сначала взять n степенью двойки.

**M05-P3.** Для T(n)=2T(n/2)+n² проверить условия подходящего случая основной теоремы. Для T(n)=T(n−1)+n объяснить, почему нужен другой метод.

**M05-P4.** Исправить рекурсивную функцию, у которой аргумент не уменьшается на одном из переходов. Выписать вход, проявляющий ошибку.

- Считать число уровней всей работой алгоритма.
- Забывать стоимость объединения подзадач.
- Применять основную теорему только по внешнему сходству записи.
