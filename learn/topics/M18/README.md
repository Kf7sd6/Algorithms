## Объяснение и порядок разбора

Одна операция может быть дорогой, а длинная последовательность иметь небольшой суммарный расход. **Амортизированная оценка** распределяет реальную работу по всем операциям серии и даёт гарантию для допустимых последовательностей. Случайное распределение входов для этого не требуется.

При удвоении вместимости динамического массива переносы дают сумму 1+2+4+… до размера порядка n, то есть O(n) переносов за n добавлений. Сами добавления тоже требуют O(n) работы. Поэтому стоимость одного добавления амортизированно O(1), хотя отдельное расширение стоит O(n). Если увеличивать вместимость только на один элемент, такой гарантии не получится.

Осваиваем суммарный, бухгалтерский методы и метод потенциалов. Для состояния D выбираем неотрицательный запас Φ(D). Учётная стоимость i-й операции: `ĉ_i=c_i+Φ(D_i)−Φ(D_{i−1})`. Суммирование телескопирует: `Σc_i=Σĉ_i+Φ(D_0)−Φ(D_m)`. При нулевом начальном и неотрицательном конечном потенциале суммарная реальная стоимость не превосходит суммарной учётной.

На **очереди из двух стеков** складываем входящие элементы в один стек, а при необходимости выдачи переносим в другой. Каждый элемент переносится лишь один раз между стеками, затем удаляется. Отдельная выдача может включать много переносов, но серия имеет линейный суммарный объём стековых действий. Сначала считаем эти действия на бумаге, потом подбираем потенциал.

Ещё один пример — двоичный счётчик: отдельное увеличение может перевернуть длинный хвост единиц, но по серии изменений есть более сильная суммарная оценка. После этих примеров можно читать потенциал фибоначчиевой кучи: он перестанет выглядеть взятой из воздуха формулой.

Мы не превращаем всю неотмеченную главу 17 в самостоятельную большую программу. Три инструмента и понятные примеры здесь нужны именно для выбранной зелёной главы о фибоначчиевых кучах.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M18-P1.** Для массива с вместимостями 1,2,4,8,… подсчитать отдельно добавления и переносы до 16 элементов. Сравнить с увеличением вместимости на 1.

**M18-P2.** Реализовать очередь из двух стеков и на серии команд посчитать число переносов. Подобрать потенциал, учитывающий элементы во входном стеке.

**M18-P3.** Посчитать число смен битов счётчика от 0 до 15. Обосновать линейную суммарную работу для n увеличений.

**M18-P4.** Объяснить на собственном примере разницу между худшей стоимостью одной операции, ожидаемой стоимостью и амортизированной стоимостью.

## Когда можно двигаться дальше

- [ ] Суммирую учётные стоимости с правильными знаками.
- [ ] Объясняю, где хранится запас для дорогого шага.
- [ ] Не называю амортизированную гарантию вероятностной.

## Частые ошибки

- Терять начальный или конечный потенциал.
- Подбирать отрицательный неограниченный запас и считать верхнюю оценку доказанной.
- Из гарантии для серии выводить константную задержку каждого шага.
