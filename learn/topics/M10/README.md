# M10. Бинарное дерево поиска

> Краткий план темы. Полный конспект с отдельной практикой ещё готовится.

**Место в программе:** Приоритет по зелёной стрелке.  
**Главы по изображению:** 12.  
**Вход:** [M03](../M03/outline.md), [M05](../M05/README.md).  
**Ориентир:** 6–10 часов первичного разбора и практики; темп уточняется по работе.

## Объяснение и порядок разбора

Дерево состоит из узлов и связей родитель — ребёнок. У бинарного дерева у узла не более двух детей. У **дерева поиска** дополнительно действует порядок: для уникальных ключей все ключи левого поддерева меньше ключа узла, правого — больше. Повторные ключи либо запрещаем, либо храним счётчик; правило фиксируем заранее.

Вставим 5,2,8,1,3. Поиск 3 сравнивает с 5, уходит влево к 2, затем вправо к 3. На каждом шаге исключается поддерево, но его размер не обязан быть половиной. Поэтому стоимость поиска, вставки и удаления — O(h), где h — высота. При последовательной вставке 1,2,3,… дерево может превратиться в цепь с h=Θ(n).

Обход «левое поддерево, узел, правое поддерево» выдаёт ключи по возрастанию. Отдельно изучаем минимум, максимум, следующего и предыдущего по порядку. Они зависят от структуры дерева и соглашения о родительских ссылках.

Удаление имеет три случая: лист; один ребёнок; два ребёнка. В последнем используем следующего по порядку узла и аккуратно меняем связи либо переносим ключ согласно выбранной реализации. После операции проверяем порядок во всех поддеревьях, связи родителей и сохранность остальных ключей.

Высоту O(log n) обеспечивают дополнительные механизмы балансировки, а не слово «бинарное». На первом проходе понимаем проблему высоты и смысл одного поворота. Полную реализацию красно-чёрного дерева из неотмеченной главы 13 в обязательный текущий маршрут не добавляем. B-деревья будут отдельной отмеченной темой M17.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M10-P1.** Построить дерево вставками 5,2,8,1,3,7,9. Выписать симметричный обход и путь поиска отсутствующего ключа 6.

**M10-P2.** Реализовать поиск, вставку и обход. Затем добавить удаление и проверить отдельно каждый из трёх случаев.

**M10-P3.** Построить вырожденное дерево и сравнить число сравнений с деревом небольшой высоты на тех же ключах.

**M10-P4.** После серии вставок и удалений сверить множество ключей с простым эталоном, а отсортированный обход — с сортировкой ключей. Проверить пустое дерево и удаление корня.

## Когда можно двигаться дальше

- [ ] Формулирую порядок для целых поддеревьев, а не только ближайших детей.
- [ ] Оцениваю операции через h и объясняю худший случай.
- [ ] Разбираю удаление корня с двумя детьми.

## Частые ошибки

- Гарантировать логарифмическую высоту произвольного BST.
- Проверять порядок только на рёбрах родитель — ребёнок.
- Путать дерево поиска с бинарной кучей.
