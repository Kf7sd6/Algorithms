# M08. Минимум, медиана и k-я порядковая статистика

> Краткий план темы. Полный конспект с отдельной практикой ещё готовится.

**Место в программе:** Приоритет по зелёной стрелке.  
**Главы по изображению:** 9.  
**Вход:** [M06](../M06/README.md).  
**Ориентир:** 4–7 часов первичного разбора и практики; темп уточняется по работе.

## Объяснение и порядок разбора

k-я порядковая статистика — значение, которое стояло бы на позиции k в отсортированном наборе. Здесь нумеруем k от 1 до n. Для `[7,1,4,4,9]` третья статистика — 4. Повторы учитываются; выбирать третье различное значение — другая задача.

Полная сортировка решает задачу за O(n log n), но упорядочивать всё необязательно. **Quickselect** выполняет разбиение и продолжает только в той части, где находится нужная позиция. При трёхчастном разбиении блок равных ключей позволяет сразу обработать повторения. Для случайного выбора опорного получаем ожидаемое O(n), а худшая стоимость обычного quickselect — O(n²).

Для гарантированного линейного времени используется **медиана медиан**: группы по пять, медианы групп, рекурсивный выбор опорного и разбиение. В анализе важно показать, какая постоянная доля элементов гарантированно отбрасывается. Получаем соотношение вида `T(n)≤T(ceil(n/5))+T(7n/10+O(1))+O(n)` и доказываем O(n). Это не базовая форма основной теоремы о равных подзадачах.

До этого разбираем отдельные задачи минимума, максимума и их одновременного нахождения попарными сравнениями. Для чётного числа значений медианой могут называть нижнюю центральную статистику, верхнюю или среднее двух центральных. Сначала фиксируем договорённость. Среднее может вообще отсутствовать среди элементов.

Этот модуль помогает увидеть, как ослабление требования к выходу делает задачу дешевле: нужен один ранг, а не весь отсортированный массив.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M08-P1.** Для [7,1,4,4,9] выписать все порядковые статистики и явно определить медиану для [1,4,8,10].

**M08-P2.** Реализовать quickselect с договорённостью о рангах и повторяющихся ключах. Проверять результат сортировкой копии на малых входах.

**M08-P3.** Найти минимум и максимум попарным методом и посчитать сравнения для чётного и нечётного n.

**M08-P4.** На рисунке групп по пять обосновать долю отбрасываемых элементов. Записать и проверить индукционную оценку медианы медиан; полную реализацию можно оставить на второй проход.

## Когда можно двигаться дальше

- [ ] Не путаю ранг с индексом и числом различных ключей.
- [ ] Объясняю ожидаемую линейность quickselect и её границы.
- [ ] Понимаю механизм гарантии медианы медиан; незавершённое доказательство фиксирую как отдельный долг.

## Частые ошибки

- Рекурсивно обрабатывать обе части как в quicksort.
- Требовать полного порядка там, где нужен только ранг.
- Объявлять медиану медиан обычным применением основной теоремы.
