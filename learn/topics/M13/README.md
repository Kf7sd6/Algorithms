## Объяснение и порядок разбора

Граф задаётся вершинами и рёбрами между ними. Разбираем ориентированный и неориентированный граф, путь, цикл, связность, степень. Начинаем с 5–7 вершин, которые можно полностью проследить вручную. Для простоты первые реализации используют вершины 0…V−1.

Матрица смежности хранит наличие рёбер для каждой пары, требует Θ(V²) памяти. Списки смежности хранят соседей каждой вершины, требуют Θ(V+E) памяти. Одно неориентированное ребро обычно записываем в двух списках; это меняет постоянный множитель, но не порядок оценки.

**Поиск в ширину (BFS)** обрабатывает очередь. Новую вершину помечаем при добавлении, чтобы она не попала в очередь многократно. В невзвешенном графе BFS находит кратчайшие пути по числу рёбер. Храним расстояние и предка; по предкам восстанавливаем маршрут. Списки смежности дают O(V+E) времени для полного обхода; с матрицей обычно O(V²).

**Поиск в глубину (DFS)** идёт по цепочке ещё не посещённых соседей, используя рекурсию или собственный стек. Разбираем время входа/выхода и три состояния вершины. Для большого графа рекурсивная глубина может переполнить стек процесса. Полный обход несвязного графа запускаем из всех ещё не посещённых вершин.

В ориентированном ациклическом графе порядок обратного выхода DFS даёт топологическую сортировку. Цикл проверяем явно; альтернативно используем алгоритм Кана с очередью вершин нулевой входящей степени. Топологический порядок существует только у DAG.

Последняя ступень — **сильно связные компоненты**: внутри каждой вершины достижимы друг из друга по направлениям рёбер. На первом проходе выбираем алгоритм Косарайю: обход, обратный порядок завершения и обход транспонированного графа. Разбираем, зачем нужны два прохода и почему граф компонент ацикличен. Тарьян, мосты, точки сочленения и LCA здесь не добавляются: они вне выбранной главы/текущего приоритета.

## Самостоятельная практика

Все задания ниже составлены для этой программы. Начинать с первого; остальные выполнять после соответствующего разбора. Готовое решение до собственной попытки не требуется.

**M13-P1.** Для рёбер 0–1, 0–2, 1–3, 2–4 построить оба представления, выполнить BFS и DFS из 0. Порядок соседей зафиксировать по возрастанию.

**M13-P2.** Реализовать BFS с восстановлением пути и подсчёт компонент неориентированного графа. Проверить изолированную вершину и недостижимую цель.

**M13-P3.** Для зависимостей 0→2, 1→2, 2→3 получить топологический порядок. Добавить 3→1 и объяснить, как обнаружится цикл.

**M13-P4.** Реализовать Косарайю. На графе с циклами 0→1→0 и 2→3→2 и ребром 1→2 выделить компоненты и построить граф компонент.

## Когда можно двигаться дальше

- [ ] Различаю направленность, достижимость и виды компонент.
- [ ] Объясняю роль очереди, стека и момента отметки.
- [ ] Доказываю кратчайший путь BFS по слоям и знаю ограничение на веса.
- [ ] Умею найти топологический порядок и сильные компоненты.

## Частые ошибки

- Запускать DFS только из одной вершины в несвязном графе.
- Выдавать BFS за кратчайшие пути с произвольными весами.
- Терять направления при построении транспонированного графа.
