# Проверенные источники

Проверка: 21 октября 2026 года. В списке официальные страницы курсов, сайты авторов и издателей. Описания ниже — краткая авторская оценка пригодности для данного маршрута. Наличие темы в источнике не означает, что пользователь обязан пройти весь этот источник.

## Пределы проведённого исследования

Сопоставлены опубликованные программы и тематические оглавления; целевые страницы и материалы преподавателя прочитаны в указанном объёме. Не заявляется чтение каждого упражнения всех перечисленных учебников или проверка кода всех реализаций. Условия задач проверены по официальным страницам; ссылки не гарантируют вечную доступность.

В комплект не включены сторонние полные учебники, лекционные копии и готовые ответы. Материалы `topics/` и собственные упражнения написаны для этого плана; ссылки ведут к оригиналам. Это даёт возможность отдельно сверять каждое сложное доказательство и не зависеть от пересказа ассистента.
