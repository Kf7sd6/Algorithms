## M01-P1.a. Индекс и значение

Дана последовательность `[8, 3, 8, 1]` длины 4. Индексы начинаются с нуля.

1. Выпиши пары «индекс — значение» для всех элементов.
2. Чем отличаются ответы на вопросы «что хранится в `a[2]`?» и «на каких позициях встречается 8?»?
3. Назови последний допустимый индекс. Какие индексы входят в `[1, 3)`? Чему равна длина этого участка?

Нужен короткий письменный ответ, программа не требуется. Это первая часть исходного M01-P1 с небольшими уточнениями границ; сдвигов здесь ещё нет.

## M01-P2. Первое вхождение

Напиши функцию поиска первого вхождения целого числа `x` в первых `n` элементах массива. Верни индекс от 0 до `n − 1`, а если значения нет — `−1`.

Для учебной реализации можно взять `std::array<int, 8>` и отдельное `n`, где `0 ≤ n ≤ 8`. Все значения помещаются в `int`. За пределами первых `n` ячеек данные последовательности отсутствуют, даже если там записаны совпадающие числа. При `n = 0` чтений массива быть не должно.

Сначала запиши алгоритм словами, затем реализуй. Проверь минимум такие случаи:

| Данные последовательности | `x` | Ожидаемый ответ |
| --- | --- | --- |
| `[5, −2, 5, 0]` | 5 | 0 |
| `[5, −2, 5, 0]` | −2 | 1 |
| `[5, −2, 5, 0]` | 9 | −1 |
| `[]` | 0 | −1 |

Назови число сравнений элементов с `x` для каждого входа. Коротко объясни, почему возвращается первое, а не произвольное вхождение. Это исходный M01-P2 с уточнённым контрактом и новыми проверками.

## M01-P1.b. Вставка, затем удаление

Начни заново с `[8, 3, 8, 1]`, `n = 4`, вместимость равна 8.

1. Вставь 6 на позицию 1, сохранив порядок старых элементов. Выпиши каждое копирование и отдельную запись нового значения. Укажи итоговую последовательность и новую длину.
2. Из **получившейся** последовательности удали первый элемент с сохранением порядка. Снова перечисли перемещения и итоговую длину.
3. Посчитай перемещения старых элементов в каждой операции. Запись нового числа и изменение длины к перемещениям не относятся.

Здесь достаточно таблицы на бумаге. Это вторая часть исходного M01-P1; операции выполняются последовательно, а не независимо от одного начального массива.

## M01-P3. Вставка и её обоснование

Реализуй вставку целого числа `x` на позицию `pos` в последовательность, хранящуюся в `std::array<int, 8>` и первых `n` его ячейках. До вызова `0 ≤ n ≤ 8`; допустимая позиция вставки — от 0 до `n` включительно. Основная задача рассматривает заранее достаточную вместимость, то есть `n < 8`.

Пусть функция возвращает `true` при успехе, меняя массив и длину у вызывающего кода. Для неверной позиции или полного буфера верни `false`, ничего не меняя. Проверку отказа достаточно сделать до сдвигов; новую память выделять не требуется.

Перед кодом на новом маленьком примере нарисуй направление сдвига. После кода поясни:

- почему перенос начинается с конца;
- какие элементы остаются на прежних местах и куда попадают остальные;
- почему цикл заканчивается;
- сколько старых элементов перемещается для длины `n` и позиции `pos`.

Формальная индукция не требуется. Нужно связное объяснение на основе движения значений. Подбери свой контрпример неверному сдвигу слева направо; используй хотя бы два разных значения в перемещаемой части.

Проверь вставку в пустую последовательность, в начало, середину и конец. Отдельно проверь отказ при полном буфере и неверной позиции. Это исходный M01-P3 с явными соглашениями и небольшим обоснованием.

## M01-P4. Сначала операции

Для каждой ситуации перечисли данные и 2–4 нужные операции, указав, чем задаётся запрос и что возвращается. Достаточно слов; реализацию выбирать не нужно.

1. Телефонная книга: по имени человека найти его номер; запись можно добавить, изменить и удалить. Для этой учебной задачи имена считаем уникальными.
2. Посещённые страницы: хранить адреса страниц и отвечать, встречался ли адрес раньше. Повторный визит не создаёт второй элемент множества.
3. Принтер: принимать задания и выдавать их в порядке поступления.

Ответ удобно оформить таблицей «данные — операция — вход — результат». Здесь исходный M01-P4; уточнены правила одинаковых ключей и порядок выдачи.

## M01-P5. Продолжение: свободное место и настоящий элемент

**Часть a.** Учебный динамический массив хранит `[7, 1, 4]`, его длина 3 и вместимость 4. Вставки делаются в конец; при заполнении вместимость удваивается. Последовательно добавь 9, затем 2.

После каждого добавления запиши последовательность, длину, вместимость и число перенесённых **старых** элементов. Запись добавляемого числа не считай переносом.

**Часть b.** Выполняется начало программы:

```cpp
std::vector<int> v{7, 1, 4};
v.reserve(10);
```

Что известно о `v.size()` и `v.capacity()`? Можно ли следующей строкой написать `v[3] = 9`? Если нет, как правильно добавить 9 и чему после этого равен размер? Точное значение вместимости угадывать не требуется. Недопустимую строку запускать не надо.

Это новое авторское задание на продолжение, а не шестая обязательная работа первого прохода.

## M01-P6 ★. Удаление без сохранения порядка

Напиши удаление по уже известному индексу `pos`, которое заменяет выбранный элемент последним и уменьшает длину. Используй тот же буфер из восьми целочисленных ячеек. При неверном индексе или пустой последовательности верни `false`, ничего не меняя.

На `[3, 7, 2, 8]` удали элемент с индексом 1. Сравни результат с удалением, сохраняющим порядок. Что останется верным, а что может измениться?

Объясни, почему этот приём не делает поиск и удаление **по значению** автоматически коротким: в условии функции уже известна позиция. Проверь удаление последнего и единственного элемента.

Это новое необязательное задание; его пропуск не препятствует переходу к M02.
