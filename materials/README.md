Выбор входа — по [стартовой проверке](../practice/00-diagnostic.md), без требования сначала прочитать весь конспект. Если выполнение присваиваний и циклов пока мешает, начать с [M00](M00/README.md): первые три части и M00-P1. Если это уже понятно, первое занятие M01 можно ограничить ячейками, индексами и одним коротким упражнением.

Готовность материала не означает, что тема уже освоена. Фактические результаты обучения находятся в [актуальном прогрессе](../CURRENT_PROGRESS.md).
