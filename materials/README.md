Для первого занятия достаточно раздела о ячейках и индексах и одного короткого упражнения. Если выполнение присваиваний и циклов пока мешает, начать с [M00](../topics/M00-programming-entry.md). Выбор входа — по [стартовой проверке](../practice/00-diagnostic.md), без требования сначала прочитать весь конспект.
