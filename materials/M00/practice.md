# M00. Практика

Основной набор — три исходных задания M00-P1–P3 из [паспорта](../../topics/M00-programming-entry.md). Новых обязательных задач нет. На сегодня достаточно одного задания после соответствующей части [конспекта](README.md).

Сначала сделай собственную попытку. Если застрял, в [помощи](help.md) есть два постепенных намёка и полный разбор каждого задания. Начать можно с русских команд и таблицы; затем перенести понятные действия в C++17.

| ID | Тип и ступень | После какой части | Проход | Обязательность |
| --- | --- | --- | --- | --- |
| M00-P1 | Ручное выполнение, 1 | §1–3: переменные и условие | Основной | Основное |
| M00-P2 | Реализация и объяснение, 2–3 | §4: цикл суммы; §6: границы и тип | Основной с проверкой границ | Основное |
| M00-P3 | Собственная функция и трасса, 3 | §5: счётчик, параметр и возврат; §6: пустота | Основной с проверкой границ | Основное |

Все три задания авторские, составлены для этой программы ранее. Здесь сохранены их ID и исходное содержание; у программ уточнены ограничения, формат результата и проверки. Числа разобранных примеров конспекта отличаются от самостоятельных трасс ниже.

## M00-P1. Присваивания и условие

По шагам выполни исходную последовательность команд; целочисленная переменная `x` уже существует:

```cpp
x = 4;
x = x + 3;
if (x > 5) {
    x = x - 2;
}
```

Выпиши значение `x` после каждой выполняемой команды. Для строки `if` отдельно запиши, что сравнивается, истинно ли условие и меняет ли сама проверка значение `x`. Объясни, почему выполняется или пропускается команда в скобках. Различи присваивание и проверку; укажи, как в C++ записать проверку равенства.

Программа не требуется: достаточно таблицы и нескольких предложений. Это исходный M00-P1, фигурные скобки только явно выделяют его ветвь.

## M00-P2. Сумма последовательности

Без копирования готовой программы прочитай `n` целых чисел и выведи их сумму.

**Ввод:** сначала целое `n`, где `0 ≤ n ≤ 200 000`, затем ровно `n` целых чисел. Каждое находится между −1 000 000 000 и 1 000 000 000 включительно. Пробелы и переводы строк между числами допустимы. Ввод корректен.

**Вывод:** одно целое число — сумма всех элементов. Для `n = 0` договорённость исходного задания сохраняется: сумма равна 0. Подписи и промежуточные значения в вывод не включаются.

Обычный пример формата:

```text
Ввод:
3
-6 1 2

Вывод:
-3
```

Пограничный пример: при вводе единственного числа `0` нужно вывести `0`, не ожидая элементов после `n`.

Сначала запиши последовательность действий словами и выбери смысл переменной, которая показывает число уже обработанных элементов. Затем напиши и запусти C++17-программу. Кратко объясни, почему каждое число добавляется ровно один раз и почему цикл заканчивается. Формальные доказательства не требуются.

Перед запуском выпиши ожидаемую сумму для проверок:

| Последовательность после `n` | Что проверяем |
| --- | --- |
| `[7, 0, −5, 2]` | Ноль и отрицательное число среди остальных; для этой последовательности выпиши состояния суммы и числа обработанных элементов |
| `[0, 0, 0]` | Каждый ноль всё равно должен быть прочитан |
| `[−8, −1, −2]` | Сумма может быть отрицательной |
| `[9]` | Единственное число |
| Четыре числа по 1 000 000 000 | Сумма может не поместиться в распространённый 32-битный `int` |
| `[]` | Пустая последовательность; ввести только `n = 0` |

Для каждой строки `n` равно количеству перечисленных элементов; квадратные скобки не вводятся. Подбери тип **до** вычисления суммы. Обоснуй, что он вмещает любую промежуточную сумму при заданных ограничениях, а не только ответы маленьких примеров.

Это исходный M00-P2. Ограничения добавлены, чтобы выбор типа можно было проверить однозначно; отдельная задача поверх исходной не создаётся.

## M00-P3. Функция подсчёта положительных

Напиши функцию, которая получает последовательность целых чисел и **возвращает количество её положительных элементов**. Положительное означает `x > 0`; ноль не учитывается. Каждое вхождение считается отдельно, даже если значения совпадают.

Длина от 0 до 200 000; значения от −1 000 000 000 до 1 000 000 000. Для пустой последовательности результат равен 0. Функция получает уже сохранённые данные, внутри неё не нужно читать ввод или печатать ответ. Можно использовать объяснённую в §5 запись параметра:

```cpp
long long count_positive(const std::vector<long long>& values);
```

Это только описание имени, параметра и типа результата; тело напиши самостоятельно. Для `std::vector` нужен `<vector>`.

На **исходном примере `[-2, 0, 5, 5]`** покажи каждое изменение счётчика. Укажи начальное состояние, результат каждой проверки и окончательный возвращаемый результат. Не заменяй количество положительных их суммой.

Проверь также пустую последовательность, `[0, −6, 0]` и `[4, 1, 9]`. Поясни, почему функция просматривает все элементы и заканчивается. Один повторный вызов на тех же данных должен дать тот же результат: счётчик начинает новый подсчёт с нуля.

Для проверки запуском можно сделать короткую `main`, которая создаёт последовательность и выводит возвращённое число. Если используешь ввод, его формат тот же: `n`, затем `n` чисел; вывод — только одно число, количество положительных.

Обычный пример формата: ввод `3 0 -6 0` даёт вывод `0`. Пограничный: ввод `0` тоже даёт `0`, но элементов в нём нет.

Это исходный M00-P3 с теми же числами ручного примера; уточнены параметр, возврат, ноль и пустота. Дополнительные проверки относятся к этой же функции.

После полного разбора самостоятельность проверяется новой короткой попыткой; просмотр решения сам по себе не подтверждает освоение.
